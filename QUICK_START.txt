================================================================================
                            SETUP IN 5 MINUTES
================================================================================

STEP 1: Get Your API Keys
───────────────────────────
1. Telegram Bot Token:
   • Open Telegram → Search @BotFather
   • Send /newbot
   • Name: "Knowledge Enhancer Bot"
   • Username: "knowledge_enhancer_bot"
   • Copy the token (like: 123456789:ABCdef...)

2. Anthropic API Key:
   • Go to console.anthropic.com
   • Sign up or login
   • Create API key
   • Copy it (starts with sk-ant-)

STEP 2: Download & Setup
────────────────────────
1. Extract KnowledgeEnhancerBot.zip
2. Rename .env.example to .env
3. Edit .env and add:
   TELEGRAM_BOT_TOKEN=your_token_here
   ANTHROPIC_API_KEY=your_key_here
   DATABASE_URL=sqlite+aiosqlite:///./knowledgebot.db

STEP 3: Install Dependencies
──────────────────────────────
pip install -r requirements.txt

STEP 4: Run the Bot
────────────────────
python bot.py

You should see:
✅ Database initialized and ready
🤖 Knowledge Enhancer Bot is running...

STEP 5: Test
─────────────
1. Open Telegram
2. Search your bot (@knowledge_enhancer_bot)
3. Send /start
4. Select subject (Math, Physics, etc.)
5. Answer questions!

================================================================================
                        CUSTOMIZATION
================================================================================

1. CHANGE DAILY LIMIT:
   In bot.py, line ~60:
   user.free_questions_today = 10  # Change from 5

2. ADD MORE SUBJECTS:
   In bot.py, line ~43:
   SUBJECTS = ["Math", "Physics", ..., "Biology"]

3. CHANGE PRICING:
   In bot.py, PREMIUM_PACKAGES dict
   "weekly": {"stars": 15, ...}  # Change from 10

4. ADJUST SCORING:
   In bot.py, update_user_rating():
   user.current_rating += 1.5  # Change from 1.0

5. CHANGE DIFFICULTY LEVELS:
   In question_generator.py, generate_question()

================================================================================
                        TROUBLESHOOTING
================================================================================

Bot doesn't respond:
→ Check token in .env
→ Check bot is running (see console for ✅)
→ Verify BotFather permissions

Questions won't generate:
→ Verify ANTHROPIC_API_KEY in .env
→ Check API key has credits
→ Review error logs

Payment not working:
→ Ensure Telegram Stars available
→ Check transaction logs
→ Verify premium expiration

Database errors:
→ SQLite: rm knowledgebot.db (fresh DB)
→ PostgreSQL: Check connection string
